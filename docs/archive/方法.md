# 制作方法

从网上公开的 Opus 5.5 视频案例和开源工程里整理出的做法（2026-10-03）。都是可选的工具，按片子需要取用。

## 一、按参考帧复刻

来源：[claude-animation-skill](../third_party/claude-animation-skill/) 的 frame-matched recreation loop。

1. 先有一张目标画面：Codex 生成的概念图、封面、用户给的参考图都可以（`tools/codex_gen.py` 用 Codex 桌面版自带 CLI 的内置生图批量出图，要有 Codex 订阅；换成别的生图工具也一样）
2. 用引擎在同一时刻渲染一帧：`bun scripts/render.ts stills --t <时刻> --only <场景> --out ../out/wip/<场景>`
3. 把目标图和渲染图左右拼在一起看（`tools/compare.py`），逐项写差距：构图、明暗分布、色相、纹理密度、线条粗细、细节层次
4. 改代码，再渲染再拼，直到差距只剩「代码画法本身的风格」

要点：目标图只当靶子，不进成片；这样「质感不够」能变成一条条可以对照修改的差距。适合样张阶段和用户说「画面质感不够」的时候。

**目标是一段视频时**（用户给了参考片、说“要这种效果 / 这个水准”）：按 [复刻配方](复刻配方.md) 第五节对照：单帧像（`tools/refmatch.py sheet`）+ 连贯（`tools/qa/seams.py`，带音乐从头连着看）+ 运动量接近（`refmatch.py motion`）三样都过才算完成。

## 二、素材来源

| 来源 | 许可 | 适合 |
|---|---|---|
| Codex 内置生图 | 自己生成 | 概念图、贴图、天空盒、背景 |
| 博物馆开放馆藏：The Met Open Access、Rijksmuseum、Art Institute of Chicago、Cleveland Museum of Art Open Access、Smithsonian Open Access | 标为 CC0 / Public Domain 的条目可商用、无需署名 | 古画、版画、纹样、老照片，当纹理、底稿、拼贴素材 |
| NYPL Public Domain Collections | 公共领域 | 老地图、插图、明信片 |
| Poly Haven | CC0 | HDRI、PBR 材质、3D 模型 |
| Google Fonts | OFL | 字体（下面单列） |

逐张核对页面上的许可标注再用，并记进成片的 `CREDITS`。公共领域素材比生成图少一层「生成感」，版权也干净。

## 三、字体

- **中文毛笔字（OFL，Google Fonts）**：马善政楷书 Ma Shan Zheng、志莽行书 Zhi Mang Xing、刘建毛草 Liu Jian Mao Cao、龙藏体 Long Cang。Lemo 的水墨 demo 用了前两种（`third_party/lemo-opuscar/styles/ink-wash/`），配合代码模拟墨色、纸纹、印泥。
- **中文正文**：思源黑体 / 思源宋体（Noto Sans SC / Noto Serif SC，OFL）。
- **中文字体太大时只取用到的字**：Google Fonts CSS API 加 `&text=<URL 编码的字>` 只返回这些字形，下载到项目的 `fonts/`，渲染时不要在线加载。
- 引擎的排版工具见 `app/src/engine/type.ts`；中英双语歌词排版见 `app/src/kit/lyrics-kit.ts`、`kit/subs.ts`。

## 四、像素风

先按低分辨率渲染（如 480×270 或 320×180），再用最近邻放大到输出尺寸。比在高分辨率上画「假像素」干净：像素网格统一，不会出现半个像素。镜头移动按整像素取整，否则画面会抖。

## 五、导演工具箱（Lemo-Opuscar `DIRECTOR.md` 摘要）

不是必须遵守的规则，是可以借的想法：

- **对标作品**：选一两部片子定标准，写清借什么、不拿什么
- **签名镜头**：观众记得住的那一个镜头（一镜到底、尺度揭示、媒介自己长出来的转场）
- **媒介特有的动作**：只有这种画风能做的变化（折纸变成转场、墨晕开成下一场）
- **节奏**：快慢交替，至少一处明确的加速或减速，给观众一次「呼吸」
- **文字停留时长**：中文约「字数 ÷ 4.5 + 1.5」秒，标题卡至少 4 秒（歌词跟唱，不受此限）
- **角色动作**：预备、动作、跟随；姿势之间用关键帧和缓动混合，不在 `if` 里直接切换；手持道具放在两手掌之间；滚动物体转角 = 距离 ÷ 半径
- 43 种画风的完整说明：`third_party/lemo-opuscar/styles/<画风>/STYLE.md`，目录见 `third_party/lemo-opuscar/styles/README.md`

## 六、审片工具

- **联系表**：`render.ts sheet`，整片每 1–2 秒一帧
- **动作帧条**：关键动作按 0.2 秒间隔（或逐帧）抽一排放大看：`render.ts sheet --from <t0> --to <t1> --n <帧数>`
- **跟随局部放大**：盯着一个世界坐标点（脚、道具）在每帧里裁一块全分辨率小图，看接触和穿模（ClaudeAnimationBase 的 `crop-at`，见 `third_party/ClaudeAnimationBase/ANIMATION_GUIDE.md` 第 3 节）
- 自动检查脚本见 `tools/qa/`

## 七、Still_Shining v10 的经验（2026-10-03）

- **「太单调」的查法**：整片每 2 秒一帧排成联系表，看是不是每帧都是同一种构图、同一种色调、同样大小的字、同样小的人。Still Shining v9 就是这样；v10 加了一层会变化的环境（云海：在云上 / 穿云 / 云在头顶 / 散尽）、换了场景（停在高楼之间）、加了近景和虚化、窗口字换了六种排法，各段平均亮度从几乎一样拉开到 0.22 – 0.58。
- **角色姿势按方向摆**：先说清上臂、前臂该指向哪里（失重时：上臂向外向前浮起、肘弯 40 – 60°、手在身前放松），用 `tools/pose_arm.py` 反解角度，再转台从 4 个方向看。靠猜欧拉角，总有某个角度像木偶或少一只手。
- **动作要连带**：不要每个关节各自随机抖（像抽搐）；用几个共同的驱动（呼吸、慢漂、乱流），从肩传到肘再传到手，一节比一节晚、幅度更大；急停时四肢带着惯性下沉再弹回。
- **截取片段的结尾**：唱完最后一个字伴奏就停，最后一个元音拖成长音、渐暗渐淡（`tools/held_note_ending.py`），画面定格、一次连续的光晕扩散；用户明确不要一下一下的回声。
- **近景不走光**：仰躺抬腿的坠落姿势，从她身前上方拍近景就是顺着大腿看进裙子，肉眼抽查会漏；用 `render.ts scan` 逐帧算。
