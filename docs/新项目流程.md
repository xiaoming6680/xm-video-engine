# 新项目流程

从一首歌到发布，用这套引擎的步骤。命令都在项目根目录运行，除非写了 `cd app`。

## 1. 建项目

```bash
python <引擎目录>/tools/new_project.py <新项目目录> [--vertical]
cd <新项目目录>/app && bun install
```

然后改 `app/src/config.ts`：画布尺寸（横 1920×1080 / 竖 1080×1920）、视频起止、输出文件名；母带很响时填 `AUDIO_FILTER`。

## 2. 音频和歌词数据

1. 歌放成 `audio/song.wav`（44.1 kHz；剪辑版先剪好再放）
2. 内嵌歌词**直接写文件，不打印**：`ffprobe -v quiet -show_entries format_tags=LYRICS -of default=nw=1:nk=1 歌.flac > data/lyrics.src.lrc`
3. 分离：`python analysis/separate.py vocals`，`python analysis/separate.py demucs`
4. 节拍和包络：`python analysis/analyze.py --bars` 看每小节的表，按听感填 `SECTION_BARS`，再 `python analysis/analyze.py`
5. 歌词对齐：`python analysis/ctc_align.py`（长歌用 `CTC_T0` / `CTC_T1` 分段）；合成人声再跑 `analysis/snap_words.py`
6. 声音事件：`python analysis/events.py --bars`，阈值不准就调。找人声切片时要避开唱词，所以排在歌词对齐之后；歌词时间改过就重跑
7. 检查：`cd app && bun scripts/render.ts info`（只列行号、时间、字数）

纯音乐不需要 2、5 两步，引擎没有歌词文件也能跑。

Python 依赖：numpy、scipy、librosa、soundfile、torch、torchaudio、audio-separator、opencv-python、Pillow、fonttools。

## 3. 设计

- `docs/TREATMENT.md`（从模板来）：先写方向、一句话、色彩剧本、场景表，用户确认后再开发
- 需要图片素材时用 Codex：提示词写进 `assets/prompts.json`，`python tools/codex_gen.py`
- 样张：用真实绘制代码出风格帧；有目标图就用 `tools/compare.py` 并排对照（`docs/方法.md`）
- 画风和模块：查基础引擎的 `docs/模块目录.md`；第三方笔刷、角色骨骼等在基础引擎的 `third_party/`

## 4. 开发

- 删掉示例场景 `app/src/scenes/demo*.ts`，在 `app/src/timeline.ts` 排自己的场景
- 写场景前读基础引擎的 `docs/引擎指南.md`（确定性、线性 HDR、图层、后期参数、运动模糊的要求）
- 预览：`cd app && bunx vite`；静帧：`bun scripts/render.ts stills --t 12.5,13 --only 场景id`，渲完**亲眼看 PNG**
- 关键动作登记到场景的 `cues()`，用 `render.ts cues` + `tools/qa/cuecheck.py` 查卡点

## 5. 每轮预览

```bash
cd app && bun scripts/render-par.ts --samples auto --max-samples 36 --shutter 0.5 --out ../out/draft/v1.mp4
cd .. && python tools/qa/review.py out/draft/v1.mp4 --start <VIDEO_START>
python tools/qa/check_video.py out/draft/v1.mp4 --douyin out/qa/douyin_test.mp4
```

按 `docs/质量验收.md` 过一遍，改完把决定写回 `docs/TREATMENT.md` 的修订记录。

## 6. 发布

- 抖音版：`python tools/douyin_mux.py <画面.mp4> audio/song.wav -o out/歌名_抖音版.mp4 [--audio-downbeat N]`
- 封面：`python tools/cover_title.py <4K 静帧> --line1 ... --line2 ...`
- `CREDITS`：引擎（MIT）、字体（OFL）、Codex 生成图、第三方代码、公共领域素材
- 发布前再跑一次 `tools/qa/check_video.py`（响度、闪光、BT.709 标签）
