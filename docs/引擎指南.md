# 引擎指南（写场景前必读）

> 这一页是写场景时必须守的规矩和骨架，读完就能动手。命令、API、后期参数全表、4K 和运动模糊的细节在 [引擎参考.md](引擎参考.md)，按需搜，不用通读。模块总览见 [模块目录.md](模块目录.md)。

## 骨架

一个场景就是一个文件 `app/src/scenes/<name>.ts`，默认导出一个继承 `Scene`（`src/engine/scene.ts`）的类：

```ts
import * as THREE from 'three';
import { Scene, type Frame } from '../engine/scene';
import { FSPass, Layer2D, W, H, clearRT } from '../engine/gl';

export default class MyScene extends Scene {
  bg = new FSPass(`uniform float t; void main(){ fragColor = vec4(C_INK, 1.0); }`, { t: { value: 0 } });
  text = new Layer2D();
  async init() { /* 构建几何体、预计算文字轮廓等 */ }
  render(f: Frame, out: THREE.WebGLRenderTarget) {
    const { renderer, comp, lyrics } = this.ctx;
    this.bg.u.t!.value = f.t;
    this.bg.render(renderer, out);            // 全屏着色器 → out（覆盖写入）
    const c = this.text.ctx; this.text.clear(); /* 用 Canvas2D 绘制 */
    comp.draw(renderer, this.text.upload(), out); // 按 alpha 叠加到 out 上
    return { bloom: 0.7 };                   // 覆盖后期参数（可选）
  }
}
```

时间线（`src/timeline.ts`）决定哪个场景在哪段时间；`ctx.params` 是条目参数，`ctx.start/ctx.end` 是窗口，`f.lt`/`f.p` 是局部时间和进度。

## 规矩

1. **输出只取决于 `f.t`。** 随机带种子（`mulberry32`、`hash`），不用 `Math.random()`、`Date.now()`、`performance.now()`。导出时一帧平均许多子帧，渲染顺序任意，逻辑不能依赖 `render()` 被调用的次数。逐帧闪烁和抖动用 `frameIdx(t)` 做种子；平面色块、字、定格的画用 `shutterT(t, 0)`，不被运动模糊糊掉；按拍步进用 `stepT` / `exposure`，每秒张数要整除导出帧率（60：30、20、15、12、10、6）。确实要积分的状态设 `stateful = true`（只能用固定的 `--samples` 导出）。细节见参考「运动模糊与采样」
2. **线性 HDR，后期默认全关。** `render()` 必须完整覆盖 `out`；颜色是线性的，线性 1 就是纯白。泛光、颗粒、高光压缩要场景自己打开（`return { bloom: 0.6, shoulder: 1 }`），pdoom 的旧外观是 `PDOOM_LOOK`。颜色用调色板：GLSL 里 `C_INK`、`C_SIGNAL`…，TS 给 GL 用 `LIN.x`，Canvas2D 用 `rgba('x', a)`。全部后期参数见参考「场景的规则和钩子」
3. **按逻辑像素排版。** 场景只用 `W`×`H`（`src/config.ts`），4K（`--scale 2`）由引擎放大；`fwidth` 定宽的发丝线写成 `pxLine`，会被放大显示的离屏 canvas 做成 `SCALE` 倍。见参考「输出缩放（4K）」
4. **跟着歌，不写死时间。** 歌词按内容查（`this.ctx.lyrics.get('…')`），小节用 `audio.timeOfBar(k)`，拍和鼓点用 `f.beat`、`f.a.kick`、`audio.events('kick', t0, t1)`。见参考「数据」
5. **连贯的运动。** 元素一直存在、属性沿缓动曲线变（效果库 `library/kit/anim.ts`），转场是同一元素在变（变形、推进穿过、分身、切开）；不要逐帧按随机数换状态凑运动量。跟拍用 `lead`（领先）不用 `follow`，缩放在对数空间（`kfz`）
6. **登记卡点和轨迹。** 关键动作写进 `cues()`（`{ t, name, on }`），主角位置写进 `track(t)`；卡点和连贯检查靠它们
7. **字。** 默认 `F.sans(weight)`（中文自动落到思源黑体）；逐字形绘制用 `layout()` / `glyphX()` 保留字偶距；`F.archivo` 宽度 100 以上是加宽字，别当默认
8. **渲完亲眼看。** `cd app && bun scripts/render.ts stills --t 12.5,13 --only <条目>`，用 Read 打开 PNG；动作用 `sheet` 拼版或抽帧看；读一读打印的 `SCENE ERRORS`。每帧目标 < 25 ms，每个场景的 Canvas2D 图层不超过 2–3 个，能预计算的放 `init()`
