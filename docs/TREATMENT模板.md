# 《歌名》

给之后的自己看：开工前和会话被压缩后先读。用不上的节删掉，想加什么就加。歌词按行号和时间戳指代，不抄进来。

## 靶子

用户认可的参考或样片：路径、要的是哪一点、不要的是哪一点。

## 用户说过的话

原话 + 范围（镜 / 段 / 全片 / 这一片）+ 日期。动到这些之前先问。

| 日期 | 范围 | 原话 | 怎么处理的 |
|---|---|---|---|

## 方向

一句话概念，歌的段落对应什么画面，配色和字体。

## 版本

版本、选择和锁定在 `film/film.json`（`tools/film.py status`）。

## 交付

成片、封面、`CREDITS`（引擎、字体、生成图、开源代码、素材）；待确认的授权。
