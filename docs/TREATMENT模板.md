# 《歌名》· 风格手册 v1

> 模板（2026-10-03）：章节骨架来自 pdoom / Falling_Again / Still_Shining 三份 TREATMENT，加上 [Lemo-Opuscar](https://github.com/lemomo-ai/lemo-opuscar) `DIRECTOR.md` 里的对标作品、镜头表和样张。
> 用法：复制到项目的 `docs/TREATMENT.md`。这是**记录决定的地方**，不是限制设计的规则：用不上的节直接删。每轮预览按引擎仓库的 `docs/质量验收.md` 查缺陷，下文提到的 `docs/方法.md`、`docs/模块目录.md` 也在引擎仓库里。
> 歌词按行号和时间戳指代，不在手册里逐行抄歌词。
> 流程见引擎仓库 `docs/新项目流程.md`：规格 → 节拍校验 → 方向样片 → 全片粗分镜 → 关键镜头打样 → 分段精做 → 发布，每一步锁定一件事。

## 已锁定

每过一步把锁定的东西记在这里。之后的意见动到这些，先说清是重开、影响哪些部分，用户同意再改。

| 项 | 锁定内容 | 哪一步 / 版本 | 日期 |
|---|---|---|---|
| 规格 | 平台、画幅、截取范围 | 0 | |
| 小节与段落 | `beatcheck` 确认的段落、drop 小节 | 1 | |
| 方向与技术路线 | 选定的方向样片 | 2 | |
| 结构 | animatic 版本（git tag） | 3 | |
| 画面标准 | 打样镜头 | 4 | |

## 零、歌曲档案

- 时长、BPM、拍号；剪辑版本（全曲还是剪辑版，起止时间）
- 段落表：`时间戳 | 段落（前奏/主歌/预副歌/副歌/间奏/drop/尾奏）| 能量（1–5）| 人声特点（长音、气口、重音的时间点）`

## 一、方向

想法、开场、结尾、整体能量走向。要给用户挑时可以列几个候选（单独写 `docs/方向提案.md`），这里只留定下来的。

## 二、一句话

全片的概念一句话；再用三行写开头 → 转折 → 结尾。

## 三、对标作品（可选）

想借某部作品的构图、节奏、镜头语法或配色时记在这里，顺手写清哪些不能拿（角色、旋律、具体镜头、logo、字体），免得版权上出问题。

| 作品 | 借什么 | 不拿什么 |
|---|---|---|

## 四、规格

画幅（横 / 竖 / 两版）、分辨率、帧率、时长；发布平台（抖音、B 站）各自的要求。

## 五、世界规则与基调

这个世界里的光、线、材质、物理；整体基调。

## 六、色彩剧本

- 调色板：色值和用途（可以从封面、对标作品或 Codex 概念图里取）
- 每段主色：`段落 | 主色 | 明暗 | 情绪`

## 七、字体与歌词

- 字体分工
- 歌词怎么出现在画面里，各场景用什么方式
- 同步规则：逐字 / 逐词跟人声起音；可提前预示多少秒；安全区

## 八、母题

贯穿全片、反复出现的元素，造型和出现规则。

## 九、场景表

按小节排（`audio.timeOfBar(k)`），和 animatic 角标的小节号一致。

| id | 小节 | 时间窗口 | 段落 | 歌词行号 | 内容 | 主色 |
|---|---|---|---|---|---|---|

## 十、镜头表

按场景列。「意图」一栏写这个镜头想让观众感到什么，方便用户审片时对照（Falling_Again 有过「运镜看不明白」的意见）。

| 场景 | 镜号 | 小节 | 景别 | 运镜 | 意图 |
|---|---|---|---|---|---|

## 十一、卡点表

关键剪辑点、关键动作落在哪一拍（`段落 + 小节 + 拍` 或时间戳）。场景在 `cues()` 里登记这些点后，`render.ts cues` + `tools/qa/cuecheck.py` 会核对偏差。

## 十二、样片与打样

- **方向样片**（第 2 步）：每个方向 10–15 秒、带声音、真实代码；文件路径、用户选了哪个、为什么
- **关键镜头打样**（第 4 步）：2–3 个成片质量的镜头；路径和确认状态。用了 Codex 概念图当目标帧时，把概念图和代码复刻图并排放在这里（方法见 `docs/方法.md`）
- **参考对照**：有参考视频的段，记下参考片段（文件、起止秒）、对照了几轮、对照图和报告路径（`refmatch.py sheet` / `motion`、`tools/qa/seams.py --ref`）；单帧像 + 连贯 + 运动量接近三样都过才算（`docs/复刻配方.md` 第五节）

## 十三、技术与交付

- 用到引擎的哪些模块（见 `docs/模块目录.md`）、渲染命令
- 交付：成片（各平台版本）、封面、`CREDITS`（片中第三方素材和许可：引擎、字体、Codex 生成图、开源代码、公共领域素材）
