# 模块目录

做一支片子时按画风和需要查这里，找到对应模块再读它的源码头注释（每个文件开头都写了用途和用法）。
「来源」一栏说明这段代码在哪个项目里实际用过，那个项目的场景代码就是现成的用法示例。

## 一、核心（每个项目都用）

| 文件 | 做什么 | 来源 |
|---|---|---|
| `src/config.ts` | 项目设置：画布尺寸、视频起止、音频路径、默认输出、音频滤镜、署名、额外字体。**新项目先改这里** | 新增 |
| `src/timeline.ts` | 剪辑表：哪个场景在哪段时间 | pdoom |
| `engine/engine.ts` | 渲染任意时刻、转场合成、自适应运动模糊、导出；`cues()` 汇总卡点 | pdoom |
| `engine/scene.ts` | 场景基类：`init` / `render(f, out)` / `cues()` | pdoom，cues 新增 |
| `engine/audio.ts` | 节拍、小节、段落、包络、起音、声音事件（`ev.of('kick')`、`ev.pulse`）、变速 | Falling_Again |
| `engine/lyrics.ts` | 逐词歌词：`get`、`lineAt`、`wordProgress`、`lineCharProgress`；没有歌词文件也能跑 | pdoom |
| `engine/gl.ts` | `FSPass` 全屏着色器、`Layer2D` 画布图层、`Compositor` 合成、`makeRT` | pdoom |
| `engine/post.ts` | 后期：辉光、光晕、色差、颗粒、暗角、闪白、震屏、缩放、反色、调色、**鱼眼、径向模糊** | pdoom + Falling_Again |
| `engine/type.ts` / `lang.ts` | 字体注册、字距排版、文字轮廓、文字采样点；中文逐字回落到思源 | pdoom |
| `engine/stroke.ts` | 单线书写字体（绘图仪、手写体），可按演唱进度「写出来」 | pdoom |
| `engine/lines.ts` | GPU 发丝线批量绘制（2D / 3D，几万到几十万条） | pdoom |
| `engine/palette.ts` | 调色板（每个项目改颜色值，键名不改） | pdoom |
| `engine/util.ts` | 缓动、弹簧、噪声、带种子随机、关键帧 `keys()`、`frameIdx` | pdoom |
| `engine/hud.ts` | 角落署名（默认关） | Falling_Again |

## 二、3D

| 文件 | 做什么 | 什么时候用 | 来源 |
|---|---|---|---|
| `engine/world.ts` | 速度连续的相机路径 `CamPath`、卡拍镜头 `ShotRig`、手持抖动、程序纹理、GTAO 环境光遮蔽 `AORender`、环境贴图、发丝线框 `Wire`、描边 `Outline` | 任何 3D 场景的相机和基础渲染 | Clarity → Falling_Again |
| `engine/kit3d.ts` | 颜色 + 深度缓冲 `GBuf`、**景深 `DofPass`**、体积光 `VolPass`、墨线 / 色阶风格化 `StylePass` | 要电影感（景深、体积光）或要把 3D 画成「画出来的」 | Clarity → Falling_Again |
| `engine/terrain.ts` | 低多边形地形、等高线梯田沙盘、水面区域 | 地形、沙丘、岛屿 | Clarity |
| `engine/voxel.ts` | 体素网格 → 一个实例化网格，带 MC 式 AO、按时间组装 / 飞散动画、文字转体素 | 方块世界、体素字 | Clarity |
| `engine/portal.ts` | 「传送门」转场：下一场透过上一场物体上的洞出现 | 场景之间要从物体里穿过去时 | Clarity |
| `engine/shards.ts` | 玻璃碎裂转场：沃罗诺伊裂纹后碎片飞向镜头 | 碎裂、冲击 | Still_Shining |
| `engine/mmd/` | three.js 的 MMD 模型加载器（MIT） | 用 MMD 角色模型时（Still_Shining 的 `teto3d.ts` 是完整用法） | Still_Shining |
| `kit/fpv.ts` | 贴地高速飞行相机（提前爬升、不穿模）、沿谷底找路线、环绕镜头；地形用 `ground` 传入 | 穿越、俯冲、一镜到底飞行 | Falling_Again |
| `kit/geo.ts` | 带顶点颜色的几何体合并、悬链线 | 程序建模（电线、城市） | Still_Shining |
| `kit/npr.ts` | 把 3D 画成动画线稿：深度 / 法线断开处出线，平涂渐变，只有发光体保留颜色 | 「代码搭 3D、画面像手绘」 | Still_Shining |
| `kit/paint.ts` | Kuwahara 油画滤镜：3D 画面重画成笔触，再拉到指定色带 | 「不要写实、要像封面那样的画」 | Falling_Again |

## 三、2D

| `engine/paper.ts` | 纸片剧场：Canvas2D 图层放进 3D 做视差，纸纹、毛边、半调、象形小人 | 平面设计 / 纸艺风 | Clarity |

| `kit/subs.ts` | 双语逐词点亮字幕（只在变化时重画） | 需要固定字幕条时 | Still_Shining |

| 手绘笔刷、铅笔、水彩晕染、角色 rig、动作游戏手感 | `claude-animation-skill/skill/lib/` |
| 写实浅水 | `clearwater/index.html` |
| p5.brush 手绘卡通流程、表演原则 | `ClaudeAnimationBase/ANIMATION_GUIDE.md` |

## 五、Python 工具（在项目根目录运行）

| 脚本 | 做什么 |
|---|---|
| `analysis/separate.py vocals` / `demucs` | 分离人声 / 四轨（模型共用 `小铭的视频基础引擎/analysis/models`） |
| `analysis/analyze.py [--bars]` | 节拍、强拍、段落、包络、起音 → `data/audio.json`（段落表每首歌改） |
| `analysis/events.py [--bars]` | 逐个声音事件（kick、snare、clap、hat、crash、riser、bass_in…）→ `data/events.json` |
| `analysis/ctc_align.py` | 歌词逐词对齐 → `data/lyrics.json`（读 `data/lyrics.src.lrc`，从不打印歌词） |
| `analysis/snap_words.py` | 合成人声的词吸附到 16 分音符格 |
| `analysis/make_fonts.py`、`make_fonts_zh.py` | 生成字体实例；中文字体按用到的字裁剪 |
| `tools/make_test_song.py` | 合成测试曲 + 数据（没有真歌时自测） |
| `tools/qa/check_video.py` | 响度、真峰值、空帧、闪光、BT.709 标签；`--douyin` 重编码看色带 |
| `tools/qa/review.py` | 联系表、运动量对 RMS 曲线、动作帧条 |
| `tools/qa/cuecheck.py` | 卡点偏差（先 `render.ts cues`） |
| `tools/compare.py` | 目标帧和渲染帧并排对照（`docs/方法.md` 第一节） |
| `tools/codex_gen.py` | Codex 批量生图（提示词写在 `assets/prompts.json`） |
| `tools/assets/clean_alpha.py`、`cutout.py`、`layers.py`、`plates.py` | 透明图去边、灰底抠角色、角色遮罩 + 深度图拆层、背景板整理 |
| `tools/douyin_mux.py` | 抖音版合成：选段配乐、锐化、淡出、保持 BT.709 |
| `tools/cover_title.py` | 发布封面（抖音 4:3 / 3:4，B 站 16:9） |
| `tools/sharpness.py` | 清晰度粗测（拉普拉斯方差） |

## 六、没收进来的

这些绑定了具体歌曲或角色，要用时去原项目里看：

- Still_Shining：`teto3d.ts`（Teto 的 MMD 角色：卡通材质、骨骼姿势、头发裙子风动；改成通用角色类要把材质名和骨骼链改成参数）、`city3d.ts`（程序生成的夜景城市）、`ss/`、`world/` 里的城镇和火车、`manga/`
- Falling_Again：沙漠、云、闪电、隧道等场景；`analysis/cut.py`（剪辑版音频）
- pdoom：P(doom) 读数、`zh.ts` 中文翻译层、各图版场景
