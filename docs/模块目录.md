# 模块目录

引擎核心（每个新项目都带）和 Python 工具。每个文件开头都写了用途和用法。
特效模块、场景级部件、示例场景和 shaders 库在效果库 `app/src/library/`（新项目不复制，目录见那里的 [README.md](../app/src/library/README.md)）。

## 一、核心

| 文件 | 做什么 | 来源 |
|---|---|---|
| `src/config.ts` | 项目设置：画布尺寸、视频起止、音频路径、默认输出、音频滤镜、署名、额外字体。**新项目先改这里** | 新增 |
| `src/timeline.ts` | 剪辑表：哪个场景在哪段时间 | pdoom |
| `engine/engine.ts` | 渲染任意时刻、转场合成、自适应运动模糊、导出；`cues()` 汇总卡点；`prepare()` 导出时每帧之前等场景逐帧加载完 | pdoom |
| `engine/scene.ts` | 场景基类：`init` / `render(f, out)` / `cues()` / 可选的 `prepare(t, t0, t1)`（逐帧加载） | pdoom |
| `engine/audio.ts` | 节拍、小节、段落、包络、起音、声音事件（`ev.of('kick')`、`ev.pulse`）、变速 | Falling_Again |
| `engine/lyrics.ts` | 逐词歌词：`get`、`lineAt`、`wordProgress`、`lineCharProgress`；没有歌词文件也能跑 | pdoom |
| `engine/gl.ts` | `FSPass` 全屏着色器、`Layer2D` 画布图层、`Compositor` 合成、`makeRT`；多采样导出时给 3D 相机加子像素抖动（网格抗锯齿）、`SUBFRAME` | pdoom |
| `engine/subframe.ts` | `SUBFRAME`：正在平均的这一帧的时刻、子帧序号、子帧在快门里的位置（抖相机、软阴影、`shutterT` 都读它） | 新增 |
| `engine/post.ts` | 后期，**默认全关**：泛光、光晕、色差、颗粒、暗角、高光压缩 `shoulder`、闪白、震屏、缩放、反色、调色、鱼眼、径向模糊；CRT、数字故障、像素排序、VHS、黑白冲击帧、像素化、遮幅、Riso 套色（补漏白、粗边、实色、错版对准重音 `risoDrift`）、VHS 红渗和撕行、调色板量化 `palette`、扫描纸纹 `paperTex`；高光压缩默认保色相 `shoulderHue`（用法见 `docs/复刻配方.md`；网址 `?post=k:v` 可临时覆盖） | pdoom + Falling_Again + 复刻配方 |
| `engine/type.ts` / `lang.ts` | 字体注册、默认文字字体 `F.sans`、字距排版、文字轮廓、文字采样点；中文逐字回落到思源 | pdoom |
| `engine/lines.ts` | GPU 发丝线批量绘制（2D / 3D，几万到几十万条） | pdoom |
| `engine/palette.ts` | 调色板（默认是中性占位，每个项目改颜色值，键名不改） | pdoom |
| `engine/util.ts` | 缓动、弹簧、噪声、带种子随机、关键帧 `keys()`、`frameIdx`；逐元素快门 `shutterT`、按拍步进 `stepT` / 摄影表 `exposure`、手放抖动 `handJitter` | pdoom |
| `engine/world.ts` | 3D：速度连续的相机路径 `CamPath`、卡拍镜头 `ShotRig`、手持抖动、程序纹理、GTAO `AORender`、环境贴图、发丝线框 `Wire`、描边 `Outline`、软阴影 `softSun` | Clarity → Falling_Again |
| `engine/kit3d.ts` | 3D：颜色 + 深度缓冲 `GBuf`、景深 `DofPass`、体积光 `VolPass`、墨线 / 色阶风格化 `StylePass` | Clarity → Falling_Again |
| `engine/hud.ts` | 角落署名（默认关） | Falling_Again |
| `engine/beatcheck.ts` | 节拍校验片（`render.ts beatcheck`） | 新增 |
| `engine/glyphcheck.ts` | 缺字检查（`render.ts glyphs`） | 新增 |
| `scenes/demo.ts`、`demo3d.ts` | 示例：2D（背景着色器、文字、逐词歌词、卡点登记）和 3D（相机路径、景深、跟着底鼓动的物体），新项目删掉 | 新增 |

## 二、Python 工具（在项目根目录运行）

| 脚本 | 做什么 |
|---|---|
| `analysis/separate.py vocals` / `demucs` | 分离人声 / 四轨（模型共用 `小铭的视频基础引擎/analysis/models`） |
| `analysis/analyze.py [--bars]` | 节拍、强拍、段落、包络、起音 → `data/audio.json`（段落表每首歌改） |
| `analysis/structure.py` | 段落草稿（SongFormer）→ `data/sections.auto.json`，打印吸附到小节线的 `SECTION_BARS` 草稿；独立环境，先跑一次 `analysis/setup_structure.py`；MuQ 权重不能商用，见 `docs/模型选型.md` |
| `analysis/ctc_align.py` | 歌词逐词对齐 → `data/lyrics.json`（读 `data/lyrics.src.lrc`，从不打印歌词） |
| `analysis/snap_words.py` | 合成人声的词吸附到 16 分音符格 |
| `analysis/events.py [--bars]` | 逐个声音事件（kick、snare、clap、hat、crash、riser、bass_in…）→ `data/events.json` |
| `analysis/make_fonts.py`、`make_fonts_zh.py` | 生成字体实例；中文字体按用到的字裁剪（改了中文就重跑）；项目自己的中文字体放 `app/public/fonts/src/zh/` 或 `--extra 文件`，裁成同一批字 |
| `tools/font_sheet.py` | 字体对比图：同一段字（中文竖排或英文签名）用 N 款字体排一张，标号、深色底、可发光、标缺字；`--lyric N` 取歌词行不写进命令。标题 / 品牌字拿不准先出这张给用户挑 |
| `tools/make_test_song.py` | 合成测试曲 + 数据（没有真歌时自测） |
| `tools/qa/check_video.py` | 响度、真峰值、音画偏移、空帧、闪光（3×3 分区）、BT.709 标签；`--douyin` 重编码看色带；`--hits` 查重击在手机频段是不是全片最响的几下 |
| `tools/qa/seams.py` | 接缝检查：每个切点前后的锚点、运动、亮度、色调、声音；`--ref` 和参考片同一处并排比 |
| `tools/qa/trackcheck.py` | 主元素轨迹：场景用 `track()` 报元素在画面上的位置（`render.ts track` 导出），查一帧瞬移、急停、交接接不上，出 x / y / 速度 / 缩放曲线 |
| `tools/qa/trail.py` | 长曝光叠帧：一段视频叠成一张图（蓝→红 = 先→后），运动路径连没连上一眼看出；`--ref` 和参考片并排 |
| `tools/qa/flowcurve.py` | 光流运动曲线：每帧整体速度、平移、推拉、跟随占比（变化里有多少是东西在移动而不是凭空出现 / 换色），标急停和抽动；`--ref` 对比 |
| `tools/qa/review.py` | 联系表、运动量对 RMS 曲线、动作帧条 |
| `tools/qa/cuecheck.py` | 卡点偏差（先 `render.ts cues`） |
| `tools/qa/test_qa.py` | 检查脚本的单元测试（`python -m unittest tools/qa/test_qa.py`） |
| `tools/held_note_ending.py` | 截取片段的结尾：最后一个元音冻结拖长、渐暗进混响；需要人声 / 伴奏两分轨 |
| `tools/douyin_mux.py` | 抖音版合成：选段配乐、锐化、淡出、保持 BT.709 |
| `tools/cover_title.py` | 发布封面（抖音 4:3 / 3:4，B 站 16:9） |
| `tools/codex_gen.py` | Codex 批量生图（提示词写在 `assets/prompts.json`）；用来做贴图、道具、背景，不当画面靶子 |
| `tools/assets/props.py` | Codex 白底贴纸（`art/raw/`）→ 透明 PNG + 轮廓 JSON（`assets/props/`）：只抠和四边相连的近白，物体里的白不动；`--see-through` 时整片近白都抠（窗户、圆环）；`--edge 10` 烤进 10 px 抗锯齿白边（贴纸）；轮廓给线沿着贴纸边走 |
| `tools/assets/clean_alpha.py`、`cutout.py`、`layers.py`、`plates.py` | 透明图去边、抠图、遮罩 + 深度图拆层（Depth Anything V2）、背景板整理 |
| `tools/refmatch.py`、`tools/grid_song.py`、`tools/compare.py` | 复刻参考视频用：抽帧、同刻对照、运动量对照（镜内变化的均值；一拍二加 `--step 2`，`--flow` 光流）、参考片原声建拍子网格、两张图并排（`docs/复刻配方.md` 第五节） |
| `tools/pose_arm.py` | 反解 MMD 手臂角度（效果库的 MMD 角色用） |
| `tools/sharpness.py` | 清晰度粗测（拉普拉斯方差） |
| `tools/blender/` | Blender 镜头渲成序列帧给引擎用（`library/kit/plate.ts`）：`render.py` 驱动（读 `data/audio.json` 的拍，逐帧打关键帧让 Cycles 运动模糊生效，按歌曲帧号出 EXR / PNG、`cam.json`、`frames.json`，断点续渲，`--still` / `--scale` / `--every` 预览），`lib.py` 渲染设置、材质、几何、灯光相机、缓动、节点插槽关键帧 `held_keys`、影棚灯带 `studio_strips`，`shots_example.py` 示例镜头，`cam_project.py` 按渲染相机把 3D 点投到画面上（给发光体补光晕、对齐字）。Blender 5 的坑见 `tools/blender/README.md`。`blender -b --factory-startup -P tools/blender/render.py -- --shots shots_example --shot drop`；Blender 不在 PATH 时写全路径 |
| `tools/fetch_refs.py` | 把第三方参考仓库（`third_party/README.md` 的清单）按固定提交拉到 `third_party/`，不进 git |
| `tts/` | 配音：造声、克隆读旁白、查错、逐字对齐（`docs/配音.md`） |
| `tools/audio/` | 配乐和音效合成（mgaudio，MIT，来自 mg-styles-15）：`sfx_mix.py` 给成片或歌叠合成音效 / wav（按 cue 或「名字@秒」，对齐画面、早一帧、闪避、母带 −14 LUFS）；`score.py` 按配方出配乐（没有歌的科普、配音片）。独立环境 `setup_audio.py`、乐器采样 `get_samples.py`（VCSL，CC0）只在基础引擎装一份，见 `tools/audio/README.md` |
