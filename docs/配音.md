# 配音（旁白类片子）

讲解、科普、自白这类要旁白的片子用 `tts/`。默认模型是 **VoxCPM2 克隆**：先按文字描述造一个纯合成音色，挑一条当参考音，再克隆它读全文。

## 为什么是 VoxCPM2

2026-10-17 在一支旁白片里做过盲听：同一段文案，都克隆同一个参考音色，五方各出 3 条，响度统一，隐去模型名。

| 候选 | 许可 | 采样率 | 结果 |
|---|---|---|---|
| **VoxCPM2 克隆**（openbmb，2B） | Apache-2.0 | 48 kHz | 和 Qwen3 难分高下，必选时选它：读得松弛，比 Qwen3 慢约 25% |
| Qwen3-TTS 1.7B 克隆 | Apache-2.0 | 24 kHz | 同上，另一个入围 |
| VoxCPM2 按描述直接造声 | Apache-2.0 | 48 kHz | 没选；每次造出的声音不一样，适合先造候选再挑 |
| IndexTTS-2.5（bilibili） | bilibili 模型许可（商用有条件） | 22 kHz | 没选 |
| Fun-CosyVoice3 0.5B | Apache-2.0 | 24 kHz | 没选 |

ASR 查下来五个都没读错，所以拉开差距的是听感，不是准确度。听感很难说清标准，挑选时可以把 2–3 条最好的直接摆出来听，附上推荐。微软 edge-tts 听感较差，没列进来。

## 装环境（基础引擎里装一次，各项目共用）

```
python tts/setup_tts.py            # 要限速就加 --rate 12M（满速大约 24 MB/s）
```

装好后是两个 venv 加三个模型，约 25 GB，都在基础引擎的 `tts/` 下，不进 git。新项目由 `tools/new_project.py` 只复制脚本，`tts/common.py` 的 `SHARED` 指回基础引擎。下面命令里的 `<E>` 指基础引擎的 `tts/`。

## 流程

文案写在 `data/script.json`：`{"lines": [{"sec": "open", "text": "字幕上的字", "say": "读法（可省）"}, ...]}`。同一 `sec` 的行连起来整段生成，段内停顿交给模型按标点处理，比一句句拼接自然。

1. **造音色**：`<E>/.venv-voxcpm/Scripts/python tts/voice.py --name 女声知性 --desc "二十五岁左右的知性女声，音色柔和饱满，有亲和力，自然不做作，语速适中，不要播音腔"`。造 3–5 种描述，每种 3 条，从里面挑。
2. **读全文**：`<E>/.venv-voxcpm/Scripts/python tts/narrate.py --ref tts/out/voices/女声知性_2.wav`。每段 3 条，输出到 `tts/out/takes/`。
3. **查错**：`<E>/.venv-asr/Scripts/python tts/check.py`。用 Qwen3-ASR 听写后算 CER，「哪 → 哪儿」这类儿化音、同音字差异可以接受。挑条标准：CER 低、语调有起伏、没有超长停顿。挑好写进 `tts/out/takes/index.json` 的 `"_chosen": {"open": "open_2.wav", ...}`。
4. **逐字时间**：`<E>/.venv-asr/Scripts/python tts/align.py`，输出 `tts/out/align.json`，每个字的起止秒数相对该段开头。
5. **拼接、配乐、字幕**：配乐可以用 `python tools/audio/score.py -o audio/score.wav --recipe explainer --duration <配音总长>` 生成（配方和卡点参数见 `tools/audio/README.md`），音效用 `tools/audio/sfx_mix.py`；拼接和逐字字幕还没收进引擎，需要时自己写：比如把各段按 BGM 小节排好，生成 `audio/vo.wav` 和逐字的 `data/lyrics.json`，再混音、做中文逐字字幕。

## 节奏

- 可以不剪停顿、不提速：试过提速 5% 加剪停顿，节奏太赶，听感变差。
- 刻意的空拍（「差在哪？」后面的思考、撞门之后）在拼接阶段按段加，不要求模型去读。

## 坑

- 含中文的路径：nagisa（qwen-asr 引入的日语分词）和 kaldifst（wetext ≥0.0.9）的 C++ 库都打不开中文路径。`check.py` / `align.py` 用空模块顶替 nagisa；用到 wetext 的模型要把 FST 复制到英文路径。
- uv 的可编辑安装（`-e`）会写一个带中文路径的 `.pth`，Python 3.11 按 GBK 读它，venv 直接起不来。所以不用 `-e` 装。
- VoxCPM 用 torchcodec 读参考音，需要 ffmpeg 的共享库版 DLL。`common.ffmpeg_dlls()` 会在加载 torch 之后去找 ffmpeg 共享库版的 `bin` 目录（路径在 `tts/common.py` 的 `_FFMPEG_DLL`，按自己的机器改）。如果先加 ffmpeg 的 DLL 目录、再加载 torch，torch 可能会用错同名 DLL。
- VoxCPM 加载权重默认用 mmap，模型建好之后再读会段错误（2026-10-17 稳定复现，原因没查到）。`common.load_voxcpm()` 已改成用 pread 读，自己写脚本时也要通过它加载。
- 显存：VoxCPM2 峰值约 6.2 GB，每条 10–15 秒（5070 Ti Laptop）。
