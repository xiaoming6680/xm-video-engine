# 质量验收清单

> 前身是一份「去 AI 味」清单（2026-10-01），2026-10-03 改成现在这样：事先规定手法会压住发挥，所以这份清单只查缺陷。
> **现在的用法**：设计时放手做，不设手法禁区，也不要求事先证明某个手法用得对；这份清单在预览时用，查有没有缺陷。查出来的问题按缺陷修，不按「像不像 AI」判断。
> **在哪一步查**（2026-10-07，见 `docs/新项目流程.md`）：以前全在成片上查，查出“单调、太碎、节奏不对”时已经要推翻。现在按步骤提前：
> - 第 2 步方向样片：第 3 条（动作有没有重量、像不像 PPT）和技术路线
> - 第 3 步全片粗分镜：第 1、2、7 条（跟着歌走、起伏、焦点、连着看连贯）和第三节“看片”的 1–4；切点跑 `tools/qa/seams.py`
> - 第 4 步关键镜头打样：画面质感、第 3 条；有参考片的镜头要**单帧像 + 连贯 + 运动量接近**（`docs/复刻配方.md` 第五节：`refmatch.py` sheet / motion / strip、`seams.py --ref`）；用户确认的打样镜头就是之后的画面标准
> - 第 5、6 步：第 4、5、6 条和第三节其余各项

## 一、成片要达到的

1. **跟着整首歌走。** 主歌、副歌、间奏、drop 的画面密度和能量对得上歌；人声的长音、气口、重音有回应；整片有起伏（密度、景别、色调），不是一个强度从头到尾。
2. **焦点清楚。** 每个时刻观众知道该看哪里；缩到手机竖屏、小窗也读得清。
3. **动作有重量。** 有预备、过冲、跟随；不同材质的东西动起来不一样。
4. **歌词读得清、跟得上。** 唱到时字已经在画面里；逐字 / 逐词跟人声起音，不提前跑在人声前面；中文按中文习惯排，不一整句同时蹦出来。
5. **经得起暂停。** 任何一帧没有穿模、溢出、错位、闪烁、糊字、空帧。
6. **技术过关。** 见第三节。
7. **连着看连贯。** 带音乐、原速、从头到尾连着看（不只看单帧、单段、慢放）：每个切点和转场有锚点或运动接住（主体在同一处、动作接着动、形状变过去），没有莫名的硬跳；镜头内部每帧都在长、在变，不是摆好的静帧在平移。

## 二、常见的返工原因

具体是哪支片、用户原话，见 [返工记录](返工记录.md)。

- 表现力不足、有劣质感 → 焦点、动作、细节（第 2、3、5 条）
- 一个强度、一种构图从头到尾（单调；有一版近九成是远景）→ 第 1 条，第 3 步粗分镜就看得出
- 场景太多太碎、运镜看不懂、冲击力不够 → 第 1、2 条
- 动作假、像 PPT 动画、技术路线撑不起画面 → 第 3 条，第 2 步方向样片就该看出来
- 方向本身不对（太压抑、主题老套、靠文字不靠画面）→ 第 2 步看
- 歌词延迟、中文一整句同时出现、某种排法读不清 → 第 4 条
- 切换时卡一下、转场生硬、过渡急 → 第 5、7 条
- 收尾不好 → 结尾落在歌的结构上（第 1 条）
- “不够高级”“像截图”这类模糊意见 → 先问清是哪里；第 4 步打样定下画面标准后，拿那几帧对照着改
- 碎片硬切、没有连续的音乐、只比单帧、镜头内部太静 → 第 7 条
- 返工最多的原因是做到整片才给用户看，见 `docs/新项目流程.md` 开头

## 三、每轮预览自查

**看片**（先带音乐、原速、从头到尾连着看一遍；再每个场景抽几帧，整片出一张联系表：`render.ts sheet`）

0. 连着看一遍：哪里接不上、哪里突然停住、哪里一跳？记下时刻，再跑 `python tools/qa/seams.py <视频>` 看那些切点的锚点、运动、亮度、色调、声音（有参考片加 `--ref`）
1. 每帧的焦点在哪？缩到 360 宽还看得清吗？
2. 联系表排开，整片有没有起伏？哪一段的密度和歌对不上？
3. 主体够大吗？有没有被挤到画面边缘、太暗看不清、同色叠同色（红底红字）、歌词压住主体？
4. 跟随主体的效果（光圈、放大、聚光）在镜头移动后还跟得住吗？这类效果统一走一个「世界坐标 → 屏幕坐标」的函数，不手写屏幕坐标
5. 关键动作（交接、落地、撞击、变形、转场）按 0.2 秒间隔抽帧条放大看；联系表每 1–2 秒一帧看不出这些问题
6. 暂停任意一帧：穿模、溢出、糊字、空帧？
7. 有角色时：转台（8 个方向）看手臂是不是贴进身体、裙摆有没有穿腿；姿势按方向摆（`tools/pose_arm.py`）
8. 有裙子的角色：`render.ts scan` 跑一遍走光检查，近景只从侧面、与她同高或上方拍（抖音色情限流）
9. 字幕在白云、亮天空上也读得清（`kit/subs.ts` 自动墨色）；截取片段的结尾唱完就停，最后一个音拖长渐隐（`tools/held_note_ending.py`）

**技术**（脚本见 `tools/qa/`，用法见 `docs/模块目录.md`）

- 响度和真峰值：发布版约 −14 LUFS，真峰值 −1 dBTP 以下
- 闪光：画面分 3×3 区，每区每秒不超过 3 次（`check_video.py`；整帧平均看不出局部大闪）
- 音画偏移 0：`check_video.py` 拿成片音轨和原曲做互相关（AAC 起始延迟要被 edit list 抵消，外部重新混流时别丢）
- 缺字：`render.ts glyphs` 列出回落到系统字体的字（颜文字符号最常见），应为 0
- 转场空帧：`blackdetect`
- 卡点偏差：场景导出的关键动作时间点和 downbeats 逐个比，看偏差毫秒数
- 用抖音常见码率重编码一遍，看暗部色带和细节
- 编码色彩：输出要按 BT.709 转换并打标签（引擎的 `render.ts` 已处理；外部重新编码时别丢）
- 首尾帧能否循环（需要循环时）
