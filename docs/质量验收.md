# 质量验收清单

> 只查缺陷，不规定怎么设计：设计放手做，预览时拿这份清单找毛病，查出来的按缺陷修。
> 用在第 2 步样片和第 3 步整片（`docs/新项目流程.md`）；以前各片被提过的意见在 `docs/archive/返工记录.md`。

## 一、成片要达到的

1. **跟着整首歌走。** 主歌、副歌、间奏、drop 的画面密度和能量对得上歌；人声的长音、气口、重音有回应；整片有起伏（密度、景别、色调），不是一个强度、一种构图从头到尾。结尾落在歌的结构上。
2. **焦点清楚。** 每个时刻观众知道该看哪里；缩到手机竖屏、小窗也读得清。
3. **动作有重量。** 有预备、过冲、跟随；不同材质的东西动起来不一样；不是摆好的静帧在平移（“像 PPT”）。
4. **歌词读得清、跟得上。** 唱到时字已经在画面里；逐字 / 逐词跟人声起音，不提前跑在人声前面；中文按中文习惯排，不一整句同时蹦出来。
5. **经得起暂停。** 任何一帧没有穿模、溢出、错位、闪烁、糊字、空帧。
6. **连着看连贯。** 带音乐、原速、从头到尾连着看：每个切点和转场有锚点或运动接住（主体在同一处、动作接着动、形状变过去），没有莫名的硬跳、卡顿；镜头内部每帧都在变。
7. **技术过关。** 见第三节。

## 二、看片

先带音乐、原速、从头到尾连着看一遍；再每个场景抽几帧，整片出一张联系表（`render.ts sheet`）。

0. 连着看：哪里接不上、哪里突然停住、哪里一跳？记下时刻，再跑 `python tools/qa/seams.py <视频>` 看那些切点的锚点、运动、亮度、色调、声音（有参考片加 `--ref`）
1. 每帧的焦点在哪？缩到 360 宽还看得清吗？
2. 联系表排开，整片有没有起伏？哪一段的密度和歌对不上？连着三个远景、整段一个构图就是问题
3. 主体够大吗？有没有被挤到画面边缘、太暗看不清、同色叠同色（红底红字）、歌词压住主体？
4. 跟随主体的效果（光圈、放大、聚光）在镜头移动后还跟得住吗？统一走一个「世界坐标 → 屏幕坐标」的函数，不手写屏幕坐标
5. 关键动作（交接、落地、撞击、变形、转场）按 0.2 秒间隔抽帧条放大看；联系表每 1–2 秒一帧看不出这些问题
6. 暂停任意一帧：穿模、溢出、糊字、空帧？
7. 字幕在白云、亮天空上也读得清；截取片段的结尾唱完就停，最后一个音拖长渐隐（`tools/held_note_ending.py`）
8. 有角色时：转台看手臂是不是贴进身体、裙摆有没有穿腿；有裙子的近景跑 `render.ts scan` 查走光（效果库 `library/engine/mmd/rig.ts`，抖音会限流）

## 三、技术

脚本在 `tools/qa/`，用法见 `docs/模块目录.md`。

- 响度和真峰值：发布版约 −14 LUFS，真峰值 −1 dBTP 以下
- 闪光：画面分 3×3 区，每区每秒不超过 3 次（`check_video.py`）
- 音画偏移 0：`check_video.py` 拿成片音轨和原曲做互相关（外部重新混流时别丢 AAC 的 edit list）
- 缺字：`render.ts glyphs` 应为 0
- 转场空帧：`blackdetect`
- 卡点偏差：`render.ts cues` + `tools/qa/cuecheck.py`
- 用抖音常见码率重编码一遍，看暗部色带和细节
- 编码色彩：BT.709 转换并打标签（`render.ts` 已处理；外部重新编码时别丢）
- 首尾帧能否循环（需要循环时）
